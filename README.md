2. Zweck der Datenverarbeitung
Dieses Anfrageformular dient ausschließlich der Bearbeitung von Tattoo-Anfragen. Die von Ihnen angegebenen Daten werden verwendet, um:
Ihre Anfrage zu bearbeiten,
mit Ihnen Kontakt aufzunehmen,
Ihr Tattoo-Projekt einzuschätzen,
ein individuelles Angebot zu erstellen,
gegebenenfalls einen Termin zu vereinbaren.
Eine Nutzung Ihrer Daten zu Werbezwecken erfolgt nicht.

Je nach Ihren Eingaben können folgende personenbezogene Daten verarbeitet werden:
Name
